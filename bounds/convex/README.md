# Аффинные оценки функции Беллмана (`bounds/convex`)

Пакет реализует построение оценок функции Беллмана из **точных значений в
известных точках** плюс **выпуклости** задачи. Везде внутри пакета работаем со
стоимостью

```
J(x, y) = -omega(x, y) >= 0
```

потому что выпукла именно она. Обёртки `bounds/lower/affine_cuts.py` и
`bounds/upper/convex_hull.py` переводят результат обратно в соглашение omega,
принятое в остальном коде.

## 1. Ключевой факт: J выпукла

Динамика линейна, множество управлений `D` выпукло, подынтегральная функция
`|x|^2/2` выпукла. Если `u1`, `u2` оптимальны для `z1`, `z2`, то управление
`theta*u1 + (1-theta)*u2` допустимо, даёт траекторию `theta*x1 + (1-theta)*x2` и
стоимость не больше выпуклой комбинации стоимостей. Значит

```
J(theta*z1 + (1-theta)*z2) <= theta*J(z1) + (1-theta)*J(z2).
```

Численная проверка на 200 случайных парах точек нарушений не нашла
(`tests/test_convex_bounds.py::test_cost_is_convex`).

Отсюда сразу следует асимметрия двух сторон, которая и определяет конструкцию.

## 2. Нижняя оценка: опорные гиперплоскости

Для выпуклой `J` любая аффинная функция `l(z) = <g, z> + c`, лежащая под `J`
**всюду**, — корректная нижняя оценка стоимости, и максимум таких функций тоже:

```
L(z) = max_k [ <g_k, z> + c_k ] <= J(z).
```

Гарантированный способ получить такую функцию — касательная в точке, где
известны и значение, и градиент:

```
l(z) = J(z0) + <grad J(z0), z - z0>.
```

Градиент известен точно на **коллинеарном множестве** `x = X e`, `y = Y e`.
Там задача сводится к 1D-Фуллеру (Зеликин–Борисов, предл. 7.8), значение равно
`-omega_1D(X, Y)`, а поперечные компоненты сопряжённых переменных равны нулю:
управление обязано быть единичным вектором вдоль `psi` и остаётся на прямой,
значит у `psi` нет поперечной части; из `psi' = -phi` и обращения сопряжённых в
нуль в момент попадания в начало координат поперечная часть `phi` тоже нулевая.
Аналитический градиент `omega_1D` сверен с конечными разностями (7e-9), а сами
отсечения проверены на 1200 точках: ни одно не превысило независимо
посчитанную верхнюю оценку.

## 3. Верхняя оценка: не аффинная, а выпуклая комбинация

Аффинной функции, лежащей **над** выпуклой `J` на всём пространстве, не
существует (кроме тривиальных случаев): `J` растёт быстрее линейной. Правильный
двойственный объект — неравенство Йенсена:

```
J( sum_i theta_i z_i ) <= sum_i theta_i J_i,   theta >= 0,  sum theta_i = 1.
```

Минимизация правой части по `theta` — линейная программа; она точна, когда
запрос сам является атомом словаря.

## 4. Важное замечание про исходную постановку

В исходной формулировке для нижней оценки предлагалось искать аффинную `l` с
условиями `l(z_i) <= J_i` только в точках выборки `S`, а затем максимизировать
её в интересующей точке. По двойственности ЛП это ровно двойственная задача к
программе Йенсена:

```
max { <g, z> + c : <g, z_i> + c <= J_i для всех i }  =  min { sum theta_i J_i : ... }.
```

То есть такая программа считает **верхнюю** оценку из п. 3, а не нижнюю.
Нижней она станет, только если ограничение `l <= J` выполнено на всей области —
полубесконечная задача. Если же навязывать `l <= current_lower` на сетке, то,
поскольку текущая нижняя оценка (описанный квадрат) сама выпукла, результат не
может её превзойти: аффинные миноранты выпуклой функции восстанавливают ровно
её саму. Поэтому режим `mode="lp"` оставлен для совместимости со спецификацией,
но помечает результат как `certified=False`.

## 5. API

```python
from bounds.convex.samples import (collinear_samples, self_similar_samples,
                                   exact_cost_if_known)
from bounds.convex.affine import (compute_lower_affine, AffineCutLowerBound,
                                  cut_at_collinear, verify_cuts)
from bounds.convex.jensen import (compute_upper_affine, JensenUpperBound)
```

* `compute_lower_affine(S, f_values, current_lower=None, targets=None, grid=None, gradients=None)`
  — если передать `gradients`, возвращает сертифицированные касательные
  отсечения; иначе решает ЛП по спецификации (несертифицированный режим).
* `compute_upper_affine(S, f_values, current_upper=None, z=...)` — значение
  Йенсена в точке `z`, веса и двойственная аффинная функция.
* `AffineCutLowerBound.cost(z)` / `.omega(x, y)` — максимум по отсечениям, с
  адаптивным подбором коллинеарной точки под запрос.
* `JensenUpperBound.cost(z)` / `.omega(x, y)` — ЛП Йенсена со словарём,
  подстроенным под запрос (масштаб Фуллера центрируется на
  `lambda = sqrt(6)|y|`, одно семейство поворотов выравнивается по направлению
  `y`, поэтому точка, лежащая на самоподобной орбите, воспроизводится точно).

Обёртки, встроенные в существующую структуру:

```python
from bounds.lower.affine_cuts import AffineCutsBound      # .lower_bound_affine(x, y)
from bounds.upper.convex_hull import ConvexHullBound      # .upper_bound_convex_hull(x, y)
```

Обе по умолчанию комбинируются с текущими оценками (`min` с квадратом и `max` с
прямоугольником в соглашении omega), поэтому результат никогда не хуже
имеющегося.

## 6. Что это даёт на практике (измерено)

В самоподобной точке (точное значение `J = 1/540 = 0.00185185`):

| оценка | J | зазор |
|---|---|---|
| квадрат (текущая нижняя) | 0.00164455 | 11.19 % |
| аффинные отсечения | 0.00137741 | 25.6 % |
| **выпуклая оболочка (Йенсен)** | **0.00185185** | **0 %** |
| прямоугольник (текущая верхняя) | 0.00191221 | 3.26 % |

* **Сверху выигрыш есть.** Йенсен со словарём, включающим самоподобную орбиту,
  даёт на ней точное значение и выигрывает у прямоугольника в окрестности
  (проверено: выигрывает при возмущении до ~2 % от нормы состояния, дальше
  проигрывает). `min(rect, jensen)` бесплатно и никогда не хуже.
* **Снизу выигрыша пока нет.** На 12 случайных точках отсечения ни разу не
  превзошли квадрат (отношение 0.985–0.999). Причина в п. 4: квадрат уже
  выпуклая нижняя оценка, а касательные у нас есть только на коллинеарном
  множестве, где квадрат и так точен.
* Пересчёт с масштабированием Фуллера (`max_lambda lambda^5 L(F_{1/lambda} z)`)
  ничего не добавляет: семейство отсечений уже замкнуто по масштабу, проверено
  численно.

## 7. Что сделало бы нижнюю оценку лучше

Нужна касательная в точке, где квадрат **не** точен, — то есть на самоподобной
орбите. Значение там известно, а градиент — нет: орбита образует
двумерную поверхность в четырёхмерном пространстве, и три доступных
соотношения (тождество Фуллера `2<phi,x> + <psi,y> = 5 omega`, инвариантность
относительно вращений `<phi, Rx> + <psi, Ry> = 0`, и HJB `<phi,y> + |psi| =
|x|^2/2`) линейно зависимы, потому что направление траектории лежит в
касательной плоскости орбиты. Численно это видно: решение вырожденной системы
даёт «отсечение», которое превышает верхнюю оценку на 2e-3, то есть не является
опорным.

Недостающие две поперечные компоненты сопряжённых переменных — это ровно та
величина, которую даёт вторая вариация / стрельба по неустойчивому многообразию
самоподобной точки. Как только они посчитаны, нижняя оценка становится точной
на орбите и улучшается в её окрестности — симметрично тому, что Йенсен уже
делает сверху.
