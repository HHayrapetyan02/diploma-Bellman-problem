# Двусторонние оценки функции Беллмана в задаче Фуллера с управлением в круге

## О проекте

Рассматривается задача оптимального управления

```
min (1/2) ∫₀^∞ ‖x‖² dt,     ẋ = y,  ẏ = u,  u ∈ D = {‖u‖ ≤ 1},  x, y ∈ ℝ²
```

— двумерный аналог задачи Фуллера с особой траекторией второго порядка в начале
координат (Зеликин–Борисов, гл. 7.2). Полный оптимальный синтез для неё
неизвестен: аналитически найдены лишь коллинеарные траектории (сводятся к
одномерной задаче Фуллера) и однопараметрическое семейство самоподобных решений.

Проект строит **двусторонние оценки функции Беллмана** и сравнивает методы между
собой на состояниях, где точный ответ известен.

### Соглашение о знаке

Везде в коде `omega = -J ≤ 0`, где `J` — стоимость. Отсюда названия папок:

* `bounds/upper` — **верхние оценки стоимости** (нижние для `omega`), то есть
  значения допустимых стратегий;
* `bounds/lower` — **нижние оценки стоимости** (верхние для `omega`), то есть
  релаксации и сертификаты.

Пакет `bounds/convex` — единственное исключение: внутри него всё считается в
стоимости `J ≥ 0`, потому что выпукла именно она; обёртки переводят результат
обратно.

### Контрольные точки

| состояние | точное значение |
|---|---|
| коллинеарные `x ∥ y` | `omega_1D(X, Y)` — одномерная задача Фуллера |
| самоподобная орбита | `J = λ⁵ / 540`, где `λ = √6 · ‖y‖` |

## `utils/` — инфраструктура

* **`constants.py`** — `Constants`: `BETA ≈ 0.4446` (корень `36β⁴ + 3β² − 2 = 0`,
  определяет кривую переключения одномерной задачи), `GAMMA ≈ 0.06753`,
  константы золотого сечения, `EPS`, `SQRT5`.
* **`utils.py`** — `OptimizationUtils`: поворот пары векторов `rotate_vectors`,
  `grid_search`, `golden_section_search`, `two_stage_optimization`
  (сетка + локальное уточнение). Используется всеми оценками, где надо
  оптимизировать угол поворота или параметр формы.
* **`geometry.py`** — выпуклые тела и инварианты:
  * `Disc`, `Polygon` с методами `support` и `argmax` (`regular_inscribed`,
    `regular_circumscribed`, `rectangle`);
  * `gramian(x, y)` — матрица Грама;
  * `to_pq / from_pq` — инварианты Фуллера `p = ‖x‖²/‖y‖⁴`, `q = ⟨x,y⟩/‖y‖³`
    (область `p ≥ q²`), сводящие задачу к двум параметрам.
* **`reduced.py`** — приведённое описание задачи:
  * `reduced_rates(x, y, u)` — динамика инвариантов при разложении управления
    `u = a·e_y + b·e_⊥`: `ṗ = (2q − 4pa)/n`, `q̇ = (1 − 2qa + √(p−q²)·b)/n`,
    `ṅ = a`. Сверена с конечными разностями полной 4-мерной системы;
  * `hjb_residual(p, q, f, f_p, f_q)` — невязка приведённого уравнения Гамильтона–Якоби–Беллмана
    `2q f_p + f_q + √((5f − 4p f_p − 2q f_q)² + (p−q²) f_q²) = p/2` для
    `omega = ‖y‖⁵ f(p, q)`. Ноль для истинной функции, `≤ 0` для субрешений;
  * `P_SELF_SIMILAR`, `Q_SELF_SIMILAR` — инварианты самоподобной орбиты
    `(2/3, −2√6/9)`, равновесие приведённой динамики.
* **`hjb.py`** — `HJBSubsolutionLP`: поиск сертификата-субрешения линейным
  программированием на сетке в `(p, q)`. Ключевые методы:
  * `build_lp` — сборка ограничений (максимум по диску заменён на максимум по
    конечному набору направлений, производные — противопотоковые);
  * `solve` — решение ЛП с боксами `f_rect ≤ f ≤ f_square` и штрафуемой
    переменной запаса;
  * `verify` — апостериорная проверка центральными разностями; сертификат
    считается корректным только при `certified=True`.

## `bounds/common.py`

* `pure_bellman_1d(x, y)` — точная функция Беллмана одномерной задачи Фуллера
  (замкнутая формула через `BETA`, `GAMMA`);
* `scaled_bellman_1d(x, y, a)` — то же для управления в `[−a, a]`,
  `= omega_1D(a·x, y)/a³`;
* `degenerate_case(x, y)` — единая обработка вырождений (нулевое состояние,
  `x = 0`, коллинеарные `x ∥ y`): возвращает точное значение либо `None`.

## `bounds/lower/` — нижние оценки стоимости

Идея: заменить круг **бо́льшим** множеством управлений — задача становится
релаксацией, её стоимость не больше исходной.

* **`square.py`** — `LowerBoundBellmanFunction`. Базовый метод: описанный
  единичный квадрат, повёрнутый на угол `φ`. Для прямоугольника задача
  распадается на две одномерные (`‖x‖² = x₁² + x₂²` аддитивна, прямоугольник —
  произведение отрезков), поэтому значение выписывается в замкнутом виде;
  оптимизация идёт только по `φ`.
* **`general_rectangle.py`** — `GeneralRectangleBound`. Помечен как устаревший
  вместе с доказательством: `[−a,a]×[−b,b] ⊇ D ⇔ a,b ≥ 1`, а значение монотонно
  по `a`, поэтому единственный минимальный по включению прямоугольник — единичный
  квадрат. Метод тождественно равен `square`; `check_monotonicity_in_a` проверяет
  монотонность численно.
* **`octagon.py`** — `OctagonBound`. Описанный восьмиугольник даёт оценку строго
  между истиной и минимумом по квадратам, но требует честного трёхмерного
  решателя (у многоугольника лишь конечная группа симметрий, редукция до двух
  параметров невозможна). Пока возвращает `square` с предупреждением.
* **`hjb_certificate.py`** — `HJBCertificateBound`. Обёртка над `HJBSubsolutionLP`:
  `fit()` решает ЛП и проверяет решение, `lower_bound_hjb(x, y)` возвращает
  сертификат, только если он прошёл проверку, иначе — `square`.
* **`affine_cuts.py`** — `AffineCutsBound`. Обёртка над аффинными отсечениями из
  `bounds/convex`, комбинируется с `square`.

## `bounds/upper/` — верхние оценки стоимости

Идея: любая допустимая стратегия даёт верхнюю оценку.

* **`rectangle.py`** — `UpperBoundBellmanFunction`. Базовый метод: вписанный
  прямоугольник со сторонами `(cos ξ, sin ξ)`, повёрнутый на `φ`; задача снова
  распадается на две одномерные. Оптимизация двумерная — по `φ` и `ξ`
  (`_adaptive_grid_search_xi` + золотое сечение).
* **`time_optimal.py`** — `TimeOptimalBound`. Реализация идеи из статьи
  Chikake–Hildebrand: аналитически решается задача **быстродействия** с тем же
  множеством допустимых траекторий, и её траектория подставляется в исходный
  функционал. `_gram_terms` — формулы грамиана через `(τ, τ̄)`, `_fit_params` —
  обращение зависимости по инвариантам `(p, q)` методом Ньютона,
  `_objective` — интегрирование стоимости.
* **`policy_improvement.py`** — `PolicyImprovementBound`. Шаг оператора Беллмана
  над уже имеющейся оценкой: `T_h[W](z) = max_u [ W(z_h(u)) − ∫₀^h ‖x‖²/2 dt ]`.
  Гарантированно `W ≤ T_h[W] ≤ omega`, то есть результат никогда не хуже старта;
  максимум берётся ещё и по нескольким шагам `h` (каждый — своя допустимая
  стратегия). Стоимость интеграла на шаге считается точно.
* **`self_similar.py`** — `SelfSimilarControlBound`. Значение функционала на
  точной самоподобной траектории (интегрирование управления
  `u = exp(i(σ√5·log(T−t) + c))` назад от начала координат). Не оценка, а
  **валидатор**: орбита занимает одну точку приведённого пространства, вне её
  метод возвращает `−inf`, а на ней обязан дать `−λ⁵/540`.
* **`polygon.py`** — `PolygonBound`. Помечен как устаревший: вписанный
  многоугольник не даёт разложения на одномерные задачи и не редуцируется до двух
  параметров. Делегирует в `policy_improvement`.
* **`convex_hull.py`** — `ConvexHullBound`. Обёртка над оценкой Йенсена из
  `bounds/convex`, комбинируется с `rectangle`.

## `bounds/convex/` — аффинные оценки из выпуклости

Опирается на то, что стоимость `J` **выпукла** (динамика линейна, множество
управлений и интегрант выпуклы). Подробный разбор — в `bounds/convex/README.md`.

* **`samples.py`** — состояния с точно известной стоимостью:
  * `cost_1d`, `grad_cost_1d` — значение и аналитический градиент одномерной
    задачи;
  * `collinear_sample`, `collinear_samples` — коллинеарные состояния вместе с
    **точным градиентом** (поперечные компоненты сопряжённых переменных равны
    нулю);
  * `self_similar_base`, `self_similar_samples` — самоподобная орбита
    (только значения), с масштабом и поворотом, подстроенными под запрос;
  * `exact_cost_if_known(z)` — распознаёт, попадает ли состояние в известное
    множество.
* **`affine.py`** — отсечения (аффинные миноранты `J`):
  * `AffineFunction` — `l(z) = ⟨g, z⟩ + c` с флагом сертифицированности;
  * `cut_from_sample`, `cut_at_collinear` — опорная гиперплоскость по значению и
    градиенту; корректна глобально в силу выпуклости;
  * `best_collinear_cut` — подбор коллинеарной точки, дающей наибольшее значение
    в запросе;
  * `compute_lower_affine(S, f_values, ...)` — при переданных градиентах строит
    сертифицированные касательные, иначе решает ЛП по коэффициентам
    (несертифицированный режим);
  * `AffineCutLowerBound` — максимум по отсечениям;
  * `verify_cuts` — необходимая проверка: ни одно отсечение не должно превышать
    независимую верхнюю оценку.
* **`jensen.py`** — выпуклая оболочка:
  * `build_dictionary(z)` — словарь атомов, подстроенный под запрос;
  * `compute_upper_affine(S, f_values, z=...)` — ЛП Йенсена
    `min Σθᵢ Jᵢ` при `Σθᵢ zᵢ = z`, `Σθᵢ = 1`; возвращает значение, веса и
    двойственную аффинную функцию;
  * `JensenUpperBound` — верхняя оценка, точная на самоподобной орбите.

Важное следствие двойственности, объясняющее асимметрию: аффинная функция,
ограниченная только в точках выборки и максимизируемая в запросе, по
двойственности ЛП даёт **верхнюю** оценку (Йенсена), а не нижнюю. Нижней она
становится только при ограничении на всей области — что бесплатно обеспечивают
касательные с точным градиентом.

## `tests/`

* **`test_benchmarks.py`** — эталонные тесты: коллинеарный случай воспроизводит
  `omega_1D` для обеих оценок; обе границы зажимают точное `−1/540`;
  `time_optimal` воспроизводит значения из статьи (`α`, `τ̄`, `τ₀` до `1e-8`);
  `self_similar` даёт точное значение с правильным знаком; приведённая динамика
  совпадает с конечными разностями; самоподобная точка — равновесие с `a²+b²=1`;
  policy improvement валиден и не хуже старта.
* **`test_convex_bounds.py`** — тесты выпуклого пакета: аналитический градиент,
  выпуклость `J`, распознавание точных значений, касание отсечений, их
  неперевышение верхней оценки, точность Йенсена на орбите, ЛП-двойственность.

Запуск: `python -m pytest tests -q`.

## `plot_bounds.py` — графики

Один скрипт, собирающий сравнение всех методов; отсутствующие модули
пропускаются, результаты кэшируются в `figures/cache_*.json`.

```
python plot_bounds.py            # рис. 1 и 2
python plot_bounds.py --grid     # + карта по приведённому пространству
```

* **Рис. 1** — срез `q = −2√6/9`, `‖y‖ = 1`, проходящий через самоподобную
  орбиту: все оценки в абсолютных величинах и в нормировке
  «0 = квадрат, 1 = прямоугольник».
* **Рис. 2** — отклонения каждого метода от точного значения в самоподобной точке.
* **Рис. 3** (по флагу) — ширина коридора «было / стало» по `(r, φ)` и карта того,
  какой метод даёт верхнюю оценку в каждой точке.

## Текущие результаты

Самоподобная точка, точное значение `J = λ⁵/540`:

| метод | отклонение | сторона |
|---|---|---|
| аффинные отсечения | 25.62 % | снизу |
| квадрат (исходная оценка) | 11.19 % | снизу |
| быстродействие | 6.81 % | сверху |
| прямоугольник (исходная оценка) | 3.26 % | сверху |
| policy improvement | 2.22 % | сверху |
| выпуклая оболочка (Йенсен) | 0.00 % | сверху |

Сверху коридор поджат: policy improvement выигрывает у прямоугольника
равномерно, Йенсен делает верхнюю оценку точной на самоподобной орбите. Снизу
исходный квадрат пока не превзойдён: он сам является выпуклой нижней оценкой, а
касательные доступны только на коллинеарном множестве, где квадрат и так точен.
Улучшение упирается в поперечные компоненты сопряжённых переменных на
самоподобной орбите — они не определяются известными соотношениями и остаются
открытым вопросом.
